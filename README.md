# Warehouse Orders V4

نظام محلي أولاً لإدارة طلبات الصالة والمستودع.

## التشغيل
- Node.js 22.22.0
- `npm install`
- `npm start`

افتراضيًا يفتح على المنفذ 3000.

## حساب المشرف الأولي
- الاسم: المشرف
- كلمة المرور: 123456

غيّر كلمة المرور من الإدارة بعد أول تشغيل.

## أهم وظائف V4
- طلب جديد سريع بحقل واحد ولوحة أرقام وحروف ومقاسات وألوان.
- ضغط مطول لإضافة `/`.
- تسجيل صوتي مع إيقاف ومعاينة.
- استلام أول موظف للمستودع.
- حد قيد التجهيز قابل للتعديل.
- خلص/جاهز لا يغلق الطلب.
- بديل لا يغلق الطلب.
- تشييك مستقل: موجود/غير موجود/يوجد بديل.
- تعديل الطلب مع قفل الطلب أثناء التعديل وتنبيه المستودع.
- تعديل الطلب بعد الإغلاق مع إعادة تعبئة النموذج.
- إرجاع الطلبات المغلقة/المنتظرة للمتابعة.
- ردود وتحويلات وسجل أحداث.
- طلبات خاصة وتنبيهات واستدعاء.
- رجيع: طلب/سحب وتعبئة كيس الرجيع.
- عروض منفصلة.
- إدارة موظفين وصلاحيات وإعدادات.
- WebSocket للتحديثات الفورية وإشارات المكالمات الصوتية.
- SQLite WAL للتخزين المحلي.

## الإنتاج المحلي
ضع السيرفر على جهاز ثابت داخل الشبكة المحلية، واجعل الأجهزة تتصل بعنوانه المحلي. يمكن إبقاء Render للاختبار فقط. إذا استخدمت Render لتجربة SQLite/ملفات الصوت، تذكر أن نظام الملفات الافتراضي مؤقت؛ التخزين الدائم يحتاج إعدادًا مناسبًا. WebSockets تحتاج إعادة اتصال تلقائي عند انقطاع الاتصال.
