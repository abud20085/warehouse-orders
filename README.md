# Warehouse Orders

نظام الصالة والمستودع لإدارة الطلبات والعروض والتشييك والرجيع.

## تشغيل محلي
```bash
npm install
npm start
```

يفتح على المنفذ الموجود في `PORT` أو 3000 افتراضيًا.

## فحص الكود
```bash
npm run check
```

## الدخول
- الصالة: اختر الصالة واكتب اسم الموظف.
- المستودع: اختر المستودع واكتب اسم الموظف.
- المشرف: اختر المشرف واكتب `المشرف`. رمز المشرف معطل افتراضيًا ويمكن تفعيله من الإعدادات.

## مبدأ المشروع
الصالة مخصصة للطلب السريع، والمستودع مخصص للرد والتنفيذ. راجع `AI_HANDOFF.md` قبل إجراء أي تعديل كبير.
