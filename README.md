# Warehouse Control Pro 6.0

نظام إدارة وتشغيل مستودع عربي RTL مع واجهة احترافية، صلاحيات، طلبات، تحليلات، سجل رقابي، إعدادات، WebSocket، وقاعدة SQLite.

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- الخدمة تستمع على `0.0.0.0` و `PORT` تلقائياً.

Render يتطلب ربط خدمة الويب على `0.0.0.0` والمنفذ الموجود في `PORT`، وهو مطبق في `server.js`.

## الدخول الأول
- المشرف: `admin` / `admin123`
- الموظف: `downstairs` / `1234`
- الموظف: `upstairs` / `1234`

غيّر كلمات المرور من النظام فوراً.

## أهم ما تم بناؤه
- RTL عربي مع فصل كامل للأرقام الإنجليزية LTR.
- لوحة تشغيل، مؤشرات، طلبات، بحث وفلاتر.
- إنشاء/تعديل/استلام/تغيير حالة/حذف الطلبات.
- حذف محمي بصلاحية المشرف مع تسجيل رقابي.
- محادثة داخل الطلب وسجل حركة.
- إدارة المستخدمين والأدوار.
- إعدادات النظام والمظهر واللون والتحديث والصلاحيات من داخل الموقع.
- تحليلات تشغيلية.
- طلبات خاصة واستدعاءات وتنبيهات.
- WebSocket للتحديثات الفورية.
- SQLite WAL وقيود foreign keys.
