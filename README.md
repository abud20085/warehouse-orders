# نظام المستودع — نموذج تشغيل سريع

## التشغيل على Render
1. ارفع الملفات إلى GitHub داخل مستودع جديد أو استبدل الملفات القديمة.
2. في Render:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Node.js 22.22.0 (مثبت لتفادي تعارض better-sqlite3 مع Node 24).
3. افتح الرابط.

## الدخول
- مشرف: كلمة المرور `123456`
- موظف صالة: اسم فقط
- موظف مستودع: اسم فقط

## ملاحظات مهمة
- قاعدة البيانات SQLite داخل `data/warehouse.db`.
- على Render المجاني، ملفات القرص قد تضيع عند إعادة تشغيل/إعادة نشر الخدمة؛ هذه النسخة مناسبة للتجربة واكتشاف الأخطاء غداً.
- للتشغيل المحلي لاحقاً على شبكة الشركة، نفس المشروع يمكن تشغيله على جهاز داخل الشركة وستبقى SQLite محلية.
- الاتصال الصوتي المباشر يحتاج السماح للميكروفون. التسجيل الصوتي مدمج أيضاً.
- هذه نسخة Prototype عملية وليست النسخة النهائية؛ الهدف أن تستخدموها غداً وتجمعوا الملاحظات قبل تثبيت كل التفاصيل.
